# SS Collections by SunShah — V4.4

## Customer experience
- Upcoming-event corner notice: informative, dismissible, non-blocking.
- Stalls & Events: one-click Yes / No / Not available feedback.
- Event discount message, including special discount note for Yes interest.
- Ask SS customer-service AI widget: English, Urdu and Roman Urdu.
- AI reads current product/event data and an order number when supplied; guarded from making sensitive business decisions.
- Request Similar / Custom Request is stored in D1 with the selected creation reference code.
- Checkout now posts the order to D1 so secure Admin sees the order.

## Owner/Admin
- Payment confirmation asks Owner/Admin for expected dispatch working days per order.
- The chosen number is stored in D1 and used in the WhatsApp confirmation text.
- Payment confirmation still permanently locks the unique product.

## AI guardrails
AI may answer routine product, event, custom-work and order-status questions. AI may not confirm payments, approve refunds, alter prices, unlock sold items, or promise exceptional discounts. Those remain Owner/Admin decisions.

## Deployment order
1. Back up/export the current D1 database.
2. Run `migrations/0003_v44_ai_events_dispatch.sql` once on the current D1 database.
3. Deploy this V4.4 Worker package over the existing UAT Worker.
4. Confirm `/api/health` shows `version: 4.4`.
5. Test one order, one custom request, one event-interest click, one AI question, and one payment confirmation with a chosen dispatch timeline.
