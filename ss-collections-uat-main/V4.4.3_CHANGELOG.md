# SS Collections V4.4.3

Focused functional correction release.

- New JSON-first Admin product creation endpoint `/api/admin/products/create`; media uploads follow as a separate authenticated R2 step.
- Retains legacy `/api/admin/products` POST for compatibility.
- ASK SS quick options now use explicit actions instead of generic free-text interpretation.
- Shop Products opens category choices inside ASK SS.
- My Order / Delivery prompts for an Order Number and uses live D1 data.
- Request Similar loads actual creation records with their own code and primary image.
- Events loads live upcoming events.
- Payment, Returns, Other Help and FAQ actions return specific information and links.
- Exact product-code lookup now carries product ID, so View/Buy actions work correctly.
- New FAQ intents for handmade, custom orders, discounts, WhatsApp contact and Handmade Journey.
- Static asset cache key advanced to 443.
